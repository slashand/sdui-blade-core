# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - Unreleased

### Added

- Browser-history coordination for durable URL and transient session blade journeys.
- A `close` action in the public SDUI action contract.

### Changed

- Native Node ESM package entry points use resolvable `.js` imports.
- Release builds clear generated output before packing, and GitHub publication requires an exact matching stable tag.

## [1.0.0] - 2026-03-21

### Added

- Initial open-source release of the Agnostic Blade System Core.
- Native ECMAScript Modules (ESM) architecture.
